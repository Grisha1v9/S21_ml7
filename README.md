# ML_7: Unsupervised Learning & Clustering

Учебный проект по курсу Machine Learning (School 21). 
В проекте исследуются методы обучения без учителя: от классического K-Means до плотностной и иерархической кластеризации, а также их применение для создания новых признаков в задаче предсказания интереса к недвижимости.

## Содержание проекта

### Task 1. Preamble & Introduction (Теория)
Разбор теоретических основ кластеризации:
- Сравнение методов инициализации центроидов K-Means: Forgy, Random Partition и K-Means++.
- Ускорение KNN с помощью кластеризации и пространственных структур данных (kd-tree).
- Метрики оценки без учителя: Silhouette coefficient и Davies-Bouldin index.
- Понятие Distortion и Elbow method.

### Task 2. Preprocessing
- Загрузка датасета Two Sigma (Rent Hop) из формата JSON.
- Кодирование целевой переменной `interest_level` (low/medium/high -> 0/1/2).
- Создание 19 бинарных признаков из списка `features` (Elevator, CatsAllowed, Doorman и т.д.) с помощью словаря маппинга.
- Очистка выбросов по цене (1% и 99% квантили) для снижения шума в Lasso.

### Task 3. K-Means (Custom & Sklearn)
- **Реализация с нуля:** Написан класс `MyKMeans` с векторизацией расстояний через `np.newaxis`, защитой от пустых кластеров и честным расчетом `inertia_`.
- **Гео-кластеризация:** Обучение на координатах `longitude`, `latitude` (30 кластеров).
- **Фича-инжиниринг:** Создан признак `distance_to_ny` (расстояние до Таймс-Сквер). 
- **Lasso:** Кластерные метки добавлены как фича. Убраны сырые координаты, чтобы кластер "заиграл". Веса Lasso адекватны (масштабированы).
- **Результат:** Продемонстрировано, что кластеризация по гео-координатам повышает информативность модели.

### Task 4. DBSCAN (Custom & Sklearn)
- **Реализация с нуля:** Написан класс `MyDBSCAN` с алгоритмом поиска в ширину (BFS) через `deque` и множества уникальных точек.
- **Параметры:** Подобраны `eps=0.01` и `min_samples=5`. Алгоритм нашел 45 естественных географических кластеров и выделил 251 точку шума.
- **Сравнение:** Метки кастомного DBSCAN на 100% совпали с метками Sklearn.
- **Результат:** DBSCAN показал отрицательный Silhouette (-0.12), что ожидаемо для кластеров сложной формы. В Lasso вес `cluster_label` составил ~0.27 (самый высокий среди всех алгоритмов).

### Task 5. AgglomerativeClustering & GaussianMixture
- Использование встроенных алгоритмов Sklearn на гео-данных (30 кластеров).
- **Agglomerative:** Silhouette = 0.4344. Обучение заняло ~14 минут из-за квадратичной сложности \(O(N^2)\).
- **GMM:** Silhouette = 0.3559. Lasso обнулил вес кластера из-за мультиколлинеарности с `distance_to_ny`.
- **Результат:** Все 4 алгоритма обучены и визуализированы на карте Нью-Йорка.

### Task 6. Clustering on 3 Features
- Выполнено требование чек-листа: кластеризация только по 3 признакам (`bedrooms`, `bathrooms`, `interest_level`).
- Обучены все 4 алгоритма (5 кластеров). Построена сетка графиков 2x2.
- **Результат:** Из-за дискретности признаков Silhouette у DBSCAN взлетел до 0.8214 (алгоритм идеально выделил плотные скопления).
